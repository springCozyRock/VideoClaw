# 分段提示词模式（wan3.0-video，720P/16:9/带音频）

服务端提示词扩写已关闭：提示词写什么就生成什么，所有关键信息必须显式写入，且用中文书写时保持术语、人名、品牌名逐字一致。

## 目录

1. 单段提示词模板
2. 声音锚点（旁白音色与 BGM 一致性）
3. 旁白台词写法
4. 参考图引用写法
5. 镜头控制：单镜头与多镜头
6. 科普/讲解画面常用视觉元素

## 1. 单段提示词模板

每段提示词按固定顺序拼装以下六块，其中【风格锚点】【声音锚点】两段文本全片逐字复用：

```text
【风格锚点】<全片统一的视觉风格描述：画风、色调、光线、质感，如"明亮干净的3D科普动画风格，蓝白主色调，柔和演播室光">
【场景与主体】<本段场景布局 + 出场角色/物体外观要点，与设定参考图对应的部分写明"与图N一致">
【画面动作】<本段发生的事：角色动作、图表出现/变化、镜头内元素调度，按时间先后写>
【镜头语言】<景别与运镜：特写/中景/全景，推/拉/摇/移/固定；默认"Single shot 单镜头">
【声音锚点】<全片统一的旁白音色 + BGM 描述，逐字复用，见第2节>
【本段旁白】<角色/旁白在本段实际说出的台词，见第3节>
```

约束提醒：

- 一段只承载一个讲解单元；画面动作要能在该段整数秒时长内自然完成，不要塞入超时内容。
- 不要在提示词里写"参考音频""与上一段声音相同"等模型无法执行的指令；一致性只靠复述锚点文本与参考图。
- 避免要求精确大段字幕文字；短句标题类文字（≤8字）成功率更高，长解释交给旁白。

## 2. 声音锚点（旁白音色与 BGM 一致性）

音频随视频一次生成且不能替换/参考，唯一的一致性手段是每段逐字复用同一段声音描述。在规划期定稿一个"声音锚点"文本资产，例如：

```text
旁白为<性别><年龄段>的中文播音嗓音，音色<温润/清亮/低沉>、语速平稳、吐字清晰、讲解语气亲和专业；
背景音乐为<风格，如轻快的企业宣传风纯音乐>，<乐器倾向>，音量始终低于人声，情绪<平稳/渐进>，全片同一首曲子风格延续。
```

规则：

- 锚点定稿后写入 plan.json 的 assets，所有含旁白的段落原样复制进提示词，禁止逐段改写同义句。
- 用户提供了参考音频时：用 `audio-understanding` 转写并让其描述音色/语速/背景声，把描述**改写成**上述锚点格式；原始音频文件本身不进入 `video-gen`。
- 需要角色对白（非旁白）时，为每个说话角色单独定一个角色声音描述（性别、年龄、音色、口吻），同样逐字复用；同一角色全片只用同一份描述。
- 无旁白的纯画面段（如片头空镜）写明"无人声，仅背景音乐延续"并复用 BGM 半句，避免音乐风格跳变。

## 3. 旁白台词写法

- 每段旁白字数 ≈ 段时长(秒) × 4~5 个汉字，留呼吸感；超时会导致语速被压快或台词被截断。
- 台词直接引号给出，标注说话人：`旁白（画外音）："……"` 或 `讲师（面对镜头）："……"`。
- 讲解词口语化、每段只讲一个点；段与段之间用衔接词（"接下来""那么""最后"）保持逻辑连贯。
- 涉及数字、步骤编号、专有名词时逐字写清（如"第一步""百分之三十"），避免模型改写。
- 口播镜头（角色面对镜头说话）音画同步靠同段生成天然对齐；仍要在自检时用 `audio-understanding` 确认台词完整。

## 4. 参考图引用写法

- `--reference-image` 的传入顺序即提示词中的图1、图2…编号；每张传入的图都必须在提示词中被显式引用并说明用途，未引用的图会浪费约束位。
- 用途句式示例：
  - `图1为讲师角色设定图，保持五官、发型、着装完全一致`
  - `图2为本段场景（实验室）关键参考，保持布局与配色一致`
  - `图3为流程示意图，画面中出现的全息图表内容与配色以它为准`
- 每段参考图总数 ≤10，优先级：角色设定图 > 场景关键图 > 物体/图表参考图 > 前段抽帧。数量吃紧时合并同类（一张图内含多个视图）。
- 前段抽帧只作辅助延续（光线、机位、进度状态），身份一致性始终以设定图为准。

## 5. 镜头控制：单镜头与多镜头

- 默认每段 `Single shot`（提示词中写明"Single shot 单镜头"），一段一镜最可控，讲解类视频以稳定的中景/特写为主。
- 确需段内切镜（如"讲师讲解 → 切到设备特写"）时在提示词中使用 `Shot cut` 关键词并逐镜描述，但注意：多镜头段的一致性风险与超时风险更高，仅在单镜头无法表达时使用，且切镜数 ≤2。
- 跨段的"镜头衔接"用剪辑思维解决：上一段结尾与下一段开头使用同景别或自然转场描述（如"镜头缓缓推近"接"特写"），不要指望模型自动接帧。
- 讲解类常用镜头组合：开场全景建立场景 → 中景口播 → 特写图表/物体 → 中景总结。把它分摊到相邻片段，而不是塞进一段。

## 6. 科普/讲解画面常用视觉元素

- 图表/示意：全息面板、悬浮箭头、剖面图、流程图卡片；在提示词中描述其出现时机与指向（"讲师挥手，身旁浮现蓝色半透明流程图，箭头依次点亮三个步骤"）。
- 强调手段：高亮圈选、放大镜特写、慢动作演示；避免依赖画面内长文字。
- 场景复用：同一讲解空间（演播室/实验室/办公室）反复出现时用同一张场景参考图 + 相同场景描述句，保证空间连续感。
- 转场段：可规划 2~4 秒的短转场段（风格化空镜 + BGM 延续 + 一句串场旁白）用于章节切换。

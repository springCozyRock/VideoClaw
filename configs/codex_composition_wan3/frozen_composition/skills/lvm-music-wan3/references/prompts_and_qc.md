## 1. 每段提示词的固定骨架

每次 video-gen 的 --prompt 按以下顺序拼装（全部用肯定式描述，避免"不要/禁止"句式）：

```
[镜头模式] Single shot: … 或含 "Shot cut" 的多镜描述
[画面主体] 出场角色逐字外观（来自角色卡）+ 动作、表情、状态（含承接上一段结尾的状态）
[环境] 场景逐字描述（来自场景卡）+ 时间/天气/光线
[镜头语言] 景别、机位、运动（推拉摇移跟升降）、转场方式
[视觉风格] 风格卡 verbatim_prompt_text
[音乐] 音乐卡 verbatim_prompt_text + 本段音乐行为（前奏响起/副歌高潮/音乐渐弱）+ 演唱内容（如适用）
[参考图说明] 图1是XX（如何使用），图2是XX（如何使用）…
```

规则：
- 音乐卡与风格卡文本逐字复用，只允许追加本段特有的音乐行为描述。
- 参考图说明必须与 --reference-image 传入顺序一一对应。
- 一段一个主要情绪；情绪转折放在段与段之间或用 "Shot cut" 分段内两镜。

## 2. 镜头语言与音乐驱动的写法

- MV 常用镜头按叙事功能选择：定场（大远景/航拍）、人物（中近景/特写）、表演（舞台机位/环绕）、情绪空镜（景物特写、光影）、群像（全景调度）。
- 能量对齐：song_structure 中 energy 高的段落使用更快的剪辑感与运动镜头（多镜 Shot cut、手持感、快速推拉）；低能量段落用长镜、慢摇、静态构图（Single shot）。
- 多镜段用 "Shot cut" 关键词并逐镜写明内容与切换动机，例如："…Shot cut to 副歌爆发：角色在雨中张开双臂，镜头快速环绕上升"。
- 剧情连贯：每段开头一句写明与上一段结尾的衔接（同一动作延续/同一场景时间推移/情绪承接），避免跳戏。

## 3. 演唱/口型与卡点

- 适配器无参考音频输入，音频由 wan3.0-video 随视频生成。演唱段在提示词中写明：角色正在演唱 + 歌词大意或直接引歌词 + 唱法情绪（如"深情地唱出'…'，口型与歌声同步"），并复述音乐卡中的人声音色描述以稳定音色。
- 不承诺与用户原曲逐字对口型；歌词用于驱动画面与演唱内容描述。
- 卡点：在提示词中写"镜头切换踩在鼓点/节拍上"，并让段长与歌曲结构边界对齐；质检时用 audio-understanding 核对节奏感与画面切换是否匹配。
- 纯器乐 MV：音乐卡 vocal 写 instrumental，提示词描述乐器演奏画面或纯意象画面与音乐的呼应。

## 4. 段级质检清单（每段生成后）

| 检查项 | 工具 | 通过标准 |
|---|---|---|
| 元数据 | get-video-metadata | 时长≈计划整数秒、1280x720、16:9、含音轨 |
| 画面一致性 | extract-video-frame + vision-understanding | 抽1–2帧对照角色卡/场景卡：发型服装、场景陈设、风格色调无明显漂移 |
| 剧情达成 | vision-understanding | 本段 plot 的核心动作/事件出现，起始状态承接上一段 |
| 音频一致性 | audio-understanding (--video --with-audio) | 曲风/乐器/人声音色与音乐卡一致，与前段无明显风格突变、无刺耳噪声 |
| 卡点/演唱 | audio-understanding + vision-understanding | 有要求时核对节奏感、演唱口型存在 |

结论与证据（帧路径、抽检回答要点）写入 observations.md 并更新 plan.json 段状态。
不合格处置顺序：改提示词/补参考图 → 重生成同段 → 仍不合格再考虑换 seed；每次重试遵守付费安全规则（SUBMISSION_UNKNOWN 或失败即停止保留现场）。

## 5. 全片质检清单（merge 后）

| 检查项 | 工具 | 通过标准 |
|---|---|---|
| 总时长/规格 | get-video-metadata | ≥目标时长（裁尾后=目标）、720P/16:9/30FPS、含音轨 |
| 全片概览 | grid-generate (by-time, ~2s) + vision-understanding | 概览格中人物/场景/风格跨段一致，剧情连贯，无明显物理异常 |
| 跨镜头一致性 | grid-generate (by-shot, frame=first) + vision-understanding | 需要更细粒度核对时使用 |
| 音频全片 | audio-understanding | 前120秒音乐风格/音色一致；更长的成片按段抽检音乐连续性与结尾收束 |
| 需求覆盖 | 对照 plan.json 与用户原始需求 | 主题、时长、音画约束、参考素材的使用均已落实并在交付说明中如实陈述 |

发现问题只重做对应段落并重走段检→合成→全片检；可接受问题记录在 observations.md，不隐瞒。

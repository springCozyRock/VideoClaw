# 一致性作业手册（动作与追逐长视频）

用于 Step 1 解析参考资料、Step 2 写 bible.md、Step 4 生成参考资产、Step 5 逐段复用。
核心前提：video-gen 是无状态的，每次调用不记得之前生成过什么；本适配器只开放文本 prompt 与参考图，没有视频参考、音频参考、首尾帧锁定。因此一致性来自三件事：**逐字复用的文字锁定短语 + 每次调用都重传的同一批参考图 + handoff 末帧与状态复述**。

## 目录

- 一致性资产类型与来源
- 用户参考资料的处理与合规化
- 角色参考图规范
- 场景与道具参考图规范

- bible.md 模板

## 一致性资产类型与来源

| 资产 | 形式 | 来源 | 用法 |
| --- | --- | --- | --- |
| 视觉风格锁定短语 | 文本 | 需求或自拟 | 每段 prompt 第 1 句逐字复用 |
| 角色外观锁定短语 | 文本（中英） | 用户描述、用户图片转写、自拟 | 每段 prompt 主体句逐字复用 |
| 角色参考图 | 图片 | 用户提供或 image-gen 生成 | 每次出现该角色都作为 `--reference-image` 传入，并在 prompt 点名图序 |
| 场景板 | 图片 | image-gen 生成 | 同一场景所有段复用同一张 |
| 道具与载具表 | 图片 + 文本 | image-gen 生成或用户图片 | 反复出现或影响剧情时传入 |
| 上一段末帧 | 图片 | extract-video-frame | 作为下一段的 handoff 参考图之一 |
| 中间片段音频特征 | 文本 | audio-understanding | 把实测到的音色与 BGM 描述回写锁定短语，供后续段复用 |
| 方向轴线与地理 | 文本 | bible.md | 每段 prompt 显式复述 |

原则：

- 用户提供的资产优先，不得被自创设定覆盖；用户资产之间冲突时，以画面/音频里实际可见可听的为准，并在 observations.md 记录取舍。
- 参考图只用于约束身份与风格，不保证锁定首尾帧，也不保证逐像素一致；相同 seed 同样不保证一致。
- 一致性资产是参考输入，不是成片素材：不要把参考图或检查用音频当作最终画面或最终音轨。
- 缺失但必要的资产自己生成（image-gen），不要因为缺资产而降低要求。

## 用户参考资料的处理与合规化

图片：

1. get-image-metadata 读宽高、格式、大小。
2. vision-understanding 读内容：人物外观、服装、道具、风格、光线、背景、是否含文字。
3. 核对 video-gen 参考图限制：JPEG/PNG/BMP/WEBP、单张 ≤20MB、边长在 240–8000 之间、**不能含透明通道**。
4. 不合规时用 image-gen `--reference-image` 转制：透明底或复杂底改纯白不透明底；单视角图扩成三视图；多角色合影拆成单角色参考；分辨率过小则重绘放大到合规边长。
5. 转制后再次 vision-understanding 自检，确认没有改变用户设定（发型、服装颜色、标志性道具必须保持）。

音频（人声或音乐）：

1. audio-understanding 转写台词、判断说话人性别与大致年龄、描述音色（音高、音质、语速、口音、情绪），描述 BGM（乐器编制、节奏快慢、风格、调性、情绪）与音效。
2. 把结果写成音色锁定短语与 BGM 锁定短语存入 bible.md。
3. 本适配器没有音频参考输入，音频文件不能直接送进 video-gen；它的唯一用途是产出可逐字复用的文字描述，以及作为最终检查时的比对基准。

视频：

1. vision-understanding `--video`（需要看声音时加 `--with-audio`）读取人物外观、服装、动作风格与节奏、场景与地理、镜头语言、色调、音色与 BGM。
2. 需要具体外观参考时，用 extract-video-frame 取清晰帧，按“图片”流程合规化后作为角色或场景参考图。
3. 视频本身不能作为 video-gen 的参考输入；只用于产出文字设定与静帧参考。

文本：整理成结构化设定（人物、场景、剧情节点、风格、音频要求），缺口按 Step 1 的规则自行补全并记录。

## 角色参考图规范

- 每个主要角色一张，纯白不透明背景，三视图（正面、侧面、背面）或“三视图 + 表情/动作小格”。
- 生成 prompt 要包含：性别与年龄段、体型、发型与发色、脸型与五官特征、肤色、服装（颜色、材质、剪裁、图案）、鞋、随身道具、标志性特征（疤痕、纹身、徽章、眼镜）、风格（写实或风格化，与全片 style_lock 一致）。
- 显式要求：纯白不透明背景、无文字、无水印、无多余人物、全身完整入画、光线均匀。
- 写实真人角色在 manifest 的 tag 用 realistic_human；拟人化或卡通角色用 unrealistic_human；动物、机械、生物用 non_human。tag 只影响评测清单，不影响生成，但必须与画面真实情况一致。
- 生成后自检：vision-understanding 确认“是否三视图、背景是否纯白、是否与锁定短语逐项一致、有无多余元素或文字、服装细节是否清晰可辨”。
- 角色在动作中会破损：如果剧情要求衣服 progressively 变脏变破，在 bible.md 写清“第几段之后服装状态改变”，并为改变后的状态单独生成一张参考图，不要指望模型自己延续破坏。

## 场景与道具参考图规范

- 每个逻辑场景一张定场板：包含空间关系（出入口、通道、拐角、高低差）、时间与天气、光源方向与色温、主色调、可破坏物件的位置。
- 同一场景多次出现只生成一次，全片复用；夜景与日景算两个场景。
- 追逐路线上的关键地标单独出图（天桥、窄巷、停车场、屋顶、市场摊位），用于强化地理连续。
- 道具与载具：只在反复出现、承载剧情或需要精确外观时出图（车、武器、背包、面具）。载具要包含损伤状态变化的版本。
- 场景板不要放人物，避免模型把参考图里的人当成必须出现的角色。

## 视觉风格锁定

style_lock 是一段固定文字，逐字复用到每段 prompt 开头，包含：

- 影像质感：写实或风格化、胶片感或数字感、颗粒、对比度
- 色调与调色：主色、辅色、饱和度倾向
- 光线：自然光或人工光、软硬、方向、时间
- 时代与地域感
- 画幅与帧率感受（720P、16:9、30FPS 由工具固定，不要在 prompt 里要求其他画幅）
- 排除项：no legible text, no subtitles, no watermark, no logo

一旦锁定不得中途改写；确需调整（例如用户要求换风格）时，所有已生成段都要重生成，成本很高，先在 observations.md 说明再动手。

## 跨段视觉漂移控制

1. 每段都传同一批参考图：主角图、对手图、场景板，再加上一段末帧。总数 ≤10，优先保证角色与场景。
2. 图序固定：全片保持“图1 主角、图2 对手、图3 场景、图4 上一段末帧”的一致约定，并在每段 prompt 中点名，避免模型混淆。
3. 锁定短语逐字复用，不要每段换措辞（换措辞等于换设定）。
4. 记录每段 seed；重生成时改 seed 会改变细节，因此非必要不改 seed，优先改 prompt 措辞或参考图。
5. 每段生成后立刻做身份比对（vision-understanding 对照参考图），发现漂移当段修，不要等到全片 QC 才批量返工。
6. 避免累积式描述：不要把前面所有段的剧情都塞进本段 prompt，只写“紧接上一刻”的状态复述 + 本段动作，长 prompt 会稀释关键约束。
7. 服装与道具状态用文字显式声明（“外套左袖已撕裂、脸上有灰尘”），不要假设模型记得。

## 音频一致性（音色、BGM、音效）

约束：本适配器没有音频参考输入，也没有语音合成、加音轨、换音轨能力；音频随每段视频一次生成，成片后无法修改。因此：

1. 音色锁定短语：为每个说话角色写一段固定描述（性别、年龄段、音高、音质如沙哑或清亮、语速、口音、情绪基调），逐字复用到该角色说话的每一段。
2. BGM 锁定短语：写清乐器编制、节奏快慢或 BPM 区间、风格、情绪、是否贯穿，逐字复用到每一段。跨调用的 BGM 不会真正无缝衔接，因此：
   - 把切点安排在动作强拍或音效突出处，弱化音乐断点
   - 不要要求“延续上一段的旋律乐句”，模型无法做到
   - 全片用同一句 BGM 描述，避免每段换风格造成明显割裂
3. 台词规范：用引号写明确台词并标明说话人；一段最多 2 句短台词；需要口型大致对齐时用正面近景；避免多人同时说话、避免侧脸长台词。
4. 音效层次：每段显式列出环境底噪、主体动作音、冲击音、BGM 三层以上，动作段至少包含脚步或引擎、风声、撞击、喘息中的一种或多种。
5. 中间片段的音频可以复用为“文字资产”：用 audio-understanding 听上一段，把实测到的音色与 BGM 描述回写进锁定短语（更贴近真实生成结果），后续段沿用，减少漂移。
6. 不要把用户提供的音频文件或检查用音频当作最终音轨；没有替换音轨的能力，只能作为文字设定与比对基准。
7. 若用户要求严格口型对齐或指定歌曲：说明能力边界（无法保证逐帧口型、无法注入指定音频文件），改用“同风格 BGM + 正面短句台词”的方案并在 observations.md 记录。

## bible.md 模板

```markdown
# Bible: {片名或任务标识}

## style_lock（逐字复用到每段 prompt 开头）
{风格锁定短语}

## direction_lock
- {角色key}: 默认向画面{左/右}移动
- 追逐地理顺序: {起点} → {地标} → {终点}
- 允许越轴的转折点: {段号与原因}

## characters
### {key}
- name: {姓名}
- tag: realistic_human | unrealistic_human | non_human
- prompt_en: {适合定位人物的英文外观短语}
- 外观锁定短语（中）: {…}
- 外观锁定短语（英）: {…}
- 服装与随身道具: {…}
- 状态变化: {第几段后外观如何改变}
- 参考图: {references/….png}
- 音色锁定短语: {…}
- 台词语种与口头禅: {…}

## scenes
### scene_{id}
- 地点/时间/天气: {…}
- 光源与色调: {…}
- 空间关系与可破坏物: {…}
- 场景板: {references/….png}
- 覆盖段号: {…}

## props
- {道具}: 外观、状态变化、参考图

## audio
- bgm_lock（逐字复用）: {…}
- sfx 层次基线: {…}
- 台词规范: 每段最多 2 句短台词，标明说话人

## forbidden
- 画面内可读文字、字幕、水印、logo、多余人物、无关旁白

## user_references
- {路径}: {类型} → {提取到的设定} → {合规化结果}
```

## 一致性检查清单

每段生成后：

- 角色身份：脸、发型、服装颜色与款式、体型是否与参考图一致
- 场景：地点、光线、色调、空间关系是否与场景板一致
- 方向：屏幕方向是否符合 direction_lock
- 距离与位置：是否与 handoff 复述衔接
- 道具与损伤：手持物、破损状态是否延续
- 人数：是否等于计划人数
- 音频：是否有声音、台词是否正确、音色是否贴近锁定短语、BGM 风格是否一致、音效是否到位

全片合成后：

- 用 grid-generate 的 by-time 与 by-shot 网格图整体看身份、服装、场景、方向的漂移
- 用 vision-understanding `--video --with-audio` 看剧情逻辑与音画一致
- 用 audio-understanding 核对同一说话人音色与 BGM 是否全片一致
- 逐条记录到 observations.md，区分“必须修”“可接受并记录”

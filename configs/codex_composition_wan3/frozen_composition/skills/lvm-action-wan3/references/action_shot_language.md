用于 Step 3 分段规划与 Step 5 prompt 组装。所有写法都必须落在 video-gen 的真实能力内：文本 prompt + 最多 10 张参考图，单段 2–30 整数秒，720P/16:9/自带音频。

## 镜头语汇与动作适配

| 镜头 | 用途 | prompt 写法要点 |
| --- | --- | --- |
| 大远景定场 | 交代地点、追逐路线、双方位置关系 | wide establishing shot，说明机位高度、时间天气、主体在画面中的位置 |
| 侧向跟拍 | 追逐主力镜头，速度感强 | tracking shot，明确“镜头与主体同速平行移动”“主体保持在画面左/右” |
| 背后跟拍 | 沉浸式追击、跑酷 | following shot from behind，主体背影居中，前方空间不断被吞掉 |
| 手持晃动 | 紧张、失控、纪实感 | handheld camera，轻微抖动，呼吸感 |
| 低角度贴地 | 脚步、车轮、速度压迫 | low angle close to the ground，前景是地面与掠过的脚或轮子 |
| 荷兰角 | 危机、失衡、反转 | dutch angle，地平线倾斜 |
| 甩镜 | 突然揭示、快速转场 | whip pan from 某物 to 某物 |
| 急推 | 强调冲击或表情瞬间 | fast push in on 面部或物体 |
| 特写插入 | 手抓边缘、按按钮、握武器、眼神 | insert close-up of 具体部位或物件 |
| 主观 POV | 代入追或被追 | POV shot，可见手臂摆动、前方障碍迎面而来 |
| 过肩 | 对峙、短台词 | over-the-shoulder shot，明确谁在前景 |
| 航拍俯视 | 展示规模与路线 | aerial drone shot following，说明高度与移动方向 |
| 长焦压缩 | 拉近双方距离、增强压迫 | telephoto compression，背景被压扁 |
| 车内镜头 | 驾驶动作、换挡、后视镜 | in-car shot，仪表台前景，挡风玻璃外景快速后退 |
| 慢动作 | 高潮冲击瞬间 | slow motion，碎屑与尘土悬浮；只短用，长用易崩 |

选镜头的原则：一段内镜头类型不超过 3 种；高强度段用短镜头 + 运动镜头；信息段（定场、转折）用稳定长镜头。

## 强度曲线与时长分配

动作/追逐片的强度曲线（按需求裁剪，不要求全部节拍都出现）：

| 节拍 | 强度 | 作用 | 建议单段时长 | 建议单镜头时长 |
| --- | --- | --- | --- | --- |
| 铺垫 | 低 | 交代人物、地点、日常状态 | 8–15 秒 | 8–15 秒 |
| 触发事件 | 中升 | 冲突爆发，动作开始 | 6–12 秒 | 4–8 秒 |
| 追逐升级 | 高 | 主力追逐，节奏加快 | 6–12 秒 | 3–6 秒 |
| 障碍或转折 | 短暂下降 | 新信息、新障碍、路线改变 | 5–10 秒 | 4–8 秒 |
| 二次追逐或反击 | 更高 | 局面反转，双方攻守易位 | 6–12 秒 | 3–5 秒 |
| 高潮对峙 | 峰值 | 正面对撞、决战、决断瞬间 | 5–10 秒 | 3–5 秒 |
| 收尾 | 下降 | 结果与余韵，留扣子 | 5–12 秒 | 5–12 秒 |

时长分配规则：

1. 所有段时长之和精确等于目标总时长，每段为 2–30 的整数秒。
2. 先按节拍分配秒数，再切成段；不要先想镜头再凑时长。
3. 高强度节拍宁可多切几段短镜头，也不要一段 30 秒的打斗（模型难以长时间维持复杂动作）。
4. 30 秒上限是硬约束，任何段不得超过；2 秒以下的段没有叙事价值，合并进相邻段。
5. 目标时长较长时，用场景变化而非重复追逐来推进，避免观众疲劳。

## 单镜头与多镜头的选择

- `Single shot`：一次调用生成一个连续长镜头。用于一镜到底追逐、定场、需要空间连续性的段落。
- `Shot cut`：一次调用内切多个镜头。用于快节奏打斗与追逐，能显著降低成本并保持节奏。写清每个镜头的内容与切换点，例如：先写镜头A的主体与动作，再写 `Shot cut to` 镜头B的场景与动作。
- 混合策略：一次调用内 2–3 个短镜头通常最稳；超过 3 个镜头时，模型容易丢失后面的镜头或混淆主体。
- 需要跨调用连续（长单镜头）时没有真正的视频续写能力，只能用 handoff 协议近似：把上一段末帧作为参考图，并在 prompt 首句复述末帧状态。因此真正的一镜到底最长只能是一段（≤30 秒）；超过 30 秒的“长镜头感”必须靠匹配剪辑伪装。

## 方向轴线与地理连续

1. 在 bible.md 写 direction_lock：每个主要角色在全片中的默认屏幕方向（例如 hero 向画面右，rival 向画面右，追者恒在被追者左侧）。
2. 每段 prompt 显式写方向词：moves toward the right of frame / enters from the left / runs away to the right。
3. 越轴只允许发生在明确转折（掉头、回身对峙、被拦截反向），并在 prompt 中写明转身动作，否则观众会觉得双方反着跑。
4. 地理连续：同一场景的空间关系（门在哪、街往哪拐、楼梯方向、可破坏物位置）写进 bible.md；同一场景再次出现时复用同一张场景板参考图。
5. 距离连续：handoff 记录双方距离（约几米）与主体在画面中的位置比例，下一段先复述再改变。
6. 追逐路线要能被观众复述：起点 → 经过的地标 → 终点，地标在镜头中反复出现以强化空间感。

## 匹配剪辑与 handoff 协议

跨调用不连续是必然的，用剪辑逻辑掩盖它：

- 出画入画匹配：上一段主体向画面右出画，下一段主体从画面左入画并继续向右。
- 动作中切（cut on action）：切点落在动作进行中（起跳、挥拳、撞门），观众注意力在动作上，忽略细节差异。
- 运动匹配：上一段向右跟拍，下一段继续向右运动或同方向甩镜。
- 姿态复述：下一段 prompt 首句写“紧接上一刻：主体右脚落地、身体前倾、右手握着包，继续向画面右方奔跑”。
- 视线匹配：上一段末尾主体看向画面右，下一段开头揭示他看到的东西。

handoff 记录字段（写进 plan.json）：

- frame_path：上一段末帧图片路径（extract-video-frame 得到）
- motion_state：姿态、速度、正在进行的动作
- screen_direction：移动方向与在画面中的位置
- distance_note：与其他角色或目标的距离
- environment_state：已被破坏或改变的物件状态

末帧只是弱上下文，必须与角色参考图、场景板和文字复述一起使用；只靠末帧会导致身份与服装漂移。

## 动作物理与打斗编排

打斗三拍：起势（可预判的准备动作）→ 接触（打击或碰撞瞬间）→ 反应（受力、后退、倒地、碎屑）。一段内只安排 1–2 个完整三拍。

物理自检清单（生成后逐项核对）：

- 肢体数量与关节方向正常，无穿模、无融合
- 人数守恒：不无故多出或缺少角色
- 打击有接触点与反作用力，不是挥空后对方自己倒
- 跳跃有起落与重力，急停有前倾惯性
- 载具轮子转动方向与行进一致，转弯有侧倾，速度感与背景位移匹配
- 手持物不瞬移、不消失、不换色
- 服装状态连续（外套破了就一直破着，湿了就一直湿着）
- 环境破坏连续（翻倒的摊位、碎玻璃、撞坏的车灯在后续镜头保持）
- 光线与天气在同一场景内不突变
- 无凭空出现或消失的物体

调度建议：复杂多人混战用镜头切换暗示规模（局部特写 + 反应镜头），不要试图在一个镜头里调度五个人的连续打斗。

## prompt 组装模板与关键词库

固定组装顺序（每段都按这个顺序，便于逐字复用锁定短语）：

```
1. 风格锁定短语（bible.md 的 style_lock，逐字复用）
2. 镜头类型与运动（single shot 或 shot cut；机位、焦段、运动方向与速度）
3. 主体锁定短语（角色外观锁定短语，逐字复用；点名“如图1所示”）
4. 本段动作与物理细节（谁、对谁、做什么、朝哪个方向、力度、接触点、反应）
5. 环境与光线（同场景锁定短语，逐字复用；点名“如图2所示”）
6. 屏幕方向与位置（direction_lock、handoff 复述）
7. 音频（引号台词 + 说话人 + 音色锁定短语；BGM 锁定短语；音效清单）
8. 排除项（no legible text, no subtitles, no watermark, no extra people）
```

多镜头写法示例结构（内容按本任务自拟，不要照抄）：

```
Single shot 或 Shot cut 关键词 + 镜头A：主体锁定短语 + 动作 + 方向 + 环境锁定短语 + 音频；
Shot cut to 镜头B：新机位 + 新动作 + 同方向 + 音频延续
```

关键词库（按需取用，保持全片用词一致）：

- 运动：sprint, dash, vault over, slide under, dodge, roll, leap, skid, drift, swerve, lunge, tackle, grapple, parry, knock back
- 镜头：tracking shot, handheld, whip pan, crash zoom, low angle, aerial drone, telephoto compression, POV, insert close-up, dutch angle
- 节奏与质感：high-speed chase, kinetic, urgent, gritty, high contrast, motion blur, dust and debris, rain-slick asphalt, neon-lit night
- 音频：footsteps on wet asphalt, engine roar, tire screech, glass shattering, heavy breathing, fabric rustle, impact thud, crowd scream, pulsing percussive score

## 动作类常见失败模式与规避写法

| 失败模式 | 规避写法 |
| --- | --- |
| 动作含糊、主体只是站着 | 写清施动者、动作、方向、接触点、受力反应；一段最多 2 个动作 |
| 主体身份漂移 | 每次调用都传同一张角色参考图，prompt 首句点名“如图1”，外观锁定短语逐字复用 |
| 画面静止、没有速度感 | 加强镜头运动（跟拍/低角度/背景位移）、加碎屑与风吹、加音效层 |
| 方向反转、双方反着跑 | 每段写死 direction_lock 词汇；越轴只在明确转折处 |
| 人数变化、多出路人 | 明确写“画面中只有 N 人”，排除多余人物 |
| 画面出现乱码文字或字幕 | 显式排除 no legible text, no subtitles, no watermark |
| 台词被吞或没人说话 | 短句、单人、正面近景，写明谁说什么；同一段不超过 2 句 |
| 只有 BGM 没有音效 | 显式列出音效清单（脚步、引擎、风声、撞击、喘息、环境底噪） |
| 静音片段 | prompt 中必须有音频描述；生成后用 audio-understanding 确认有声音 |
| 长段打斗后半崩掉 | 拆成多段或一次调用内 2–3 个短镜头，别把 30 秒全给打斗 |
| 慢动作过度导致形变 | 慢动作只在高潮的短瞬间使用 |
| 环境破坏自动复原 | handoff 记录 environment_state，下一段 prompt 复述破坏状态 |

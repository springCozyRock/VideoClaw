## 1. 提示词结构模板

服务端提示词扩写已关闭，模型只会看到你写的文本。每段提示词按固定顺序拼装，
其中【风格块】【音频块】全片逐字复用（定义见 planning_and_assets.md）：

```
[镜头语言：景别+运镜+机位] [主体与动作：谁/什么，在做什么，情绪] [场景与环境：地点、时间、天气、陈设] [光影与色彩] [衔接说明：与参考图/上一段的关系] 【风格块】 【音频块】 [本段台词/旁白（如有）]
```

参考图指称必须与传参顺序一致：提示词里写「图1中的角色」「图2的场景」，
`--reference-image` 就按同样顺序传入。

## 2. 单镜头与多镜头

- 单镜头段：提示词以「Single shot:」开头，段内不允许切镜；用于长镜头、一镜到底续接段、需要时间连续性的运镜展示。
- 多镜头段：在切点处写「Shot cut to ...」，一次调用可含 2–3 个镜头；用于蒙太奇、快节奏展示。切点越多可控性越低，关键一致性镜头优先拆成独立单镜头段。
- 段与段的拼接点天然是硬切；跨段「无缝续接」只能靠尾帧参考图 + 单镜头写法逼近。

## 3. 景别词汇

大远景(extreme wide) / 远景(wide) / 全景(full) / 中景(medium) / 近景(medium close-up) /
特写(close-up) / 大特写(extreme close-up)。
展示类视频建议相邻段景别有明确对比（如远景交代 → 特写细节），避免全片同一景别。

## 4. 运镜词汇

推(dolly in / push in)、拉(dolly out / pull back)、摇(pan 左右 / tilt 上下)、
移(tracking / trucking)、跟(follow)、升降(crane up/down)、环绕(arc / orbit around)、
手持(handheld 轻微晃动)、稳定器(smooth stabilized)、变焦(zoom in/out)、
甩镜(whip pan，作转场)、第一人称(POV)、航拍(aerial / drone)。
每段选 1–2 种主运镜写清楚方向与速度（缓慢/匀速/快速），运镜本身就是展示类视频的主体内容。

## 5. 光影·色彩·质感

可用维度：光源性质（自然光/黄金时刻/蓝调时刻/硬光/柔光/逆光/剪影/霓虹/烛光/丁达尔光束）、
色调（暖调/冷调/青橙/低饱和/高对比/单色点缀）、质感（胶片颗粒/数字干净/雾霭/雨雪/尘埃）。
这些描述放进每段提示词，稳定复现的部分沉淀进【风格块】。

## 6. 节奏与段时长选择

- 静态景观、缓慢运镜、一镜到底续接：10–30 秒长段。
- 常规叙事镜头：5–10 秒。
- 快切蒙太奇：用多镜头段（Shot cut）承载 2–3 个 2–4 秒镜头，而不是生成大量 2 秒碎段。
- 段数估算：ceil(D_total / 平均段长)；合计时长留出 5–10% 余量供 merge 裁尾，但不得少于 D_total。

## 7. 音频块写法

wan3.0-video 随段生成音频，无法传音频参考，一致性全靠文本：

- BGM：一句固定描述（风格、乐器、速度、情绪），逐字复用；某段需要 BGM 变化（如高潮）时，在该段音频块后追加变化句，但保留基础描述。
- 音色：每个说话角色一句固定描述（性别、年龄感、音质、语速、口音/语种），逐字复用；旁白与角色台词分别标明说话人。
- 环境音/音效：写与画面同步的关键音效（脚步、雨声、引擎），避免与 BGM 描述冲突。
- 无人声需求时显式写「无人声，仅 BGM 与环境音」，防止模型自行加旁白。

## 8. 展示类视频的镜头设计原则

- 让镜头语言承担叙事：每段有一个明确的「镜头看点」（一种运镜、一种光影、一次景别转换），并在提示词开头强调。
- 全片形成结构：开场定调（远景/航拍+主题音乐）→ 展开（多样景别与运镜的递进）→ 高潮（最强对比的光影/最快节奏）→ 收尾（拉远/渐静）。剧情逻辑连贯，段与段之间有明确的时空或情绪衔接。
- 反复出现的主体（人物/标志物）是一致性锚点，每次出现挂同一参考图。

## 9. 写作注意事项

- 提示词用与目标视频受众匹配的语言书写（中文需求默认中文提示词；台词语种按用户要求）。
- 具体优于抽象：「镜头自左向右缓慢横移，掠过摆满旧书的长桌，桌灯暖光」优于「一个好看的书房镜头」。
- 一段提示词只写该段 2–30 秒内能完成的内容，不要塞入需要更长时间的复杂事件链。
- 不要在提示词里引用「上一段」的隐性记忆；衔接信息用尾帧参考图 + 显式文字（「延续图3画面，同一机位继续推进」）表达。
